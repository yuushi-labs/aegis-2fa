# 配布用の署名鍵（公開情報）

`zekey-debug.keystore` は **配布用の固定署名鍵** です。`signing.properties` に書いてある
パスワードも含めて公開しています。秘密情報ではありません。

## なぜコミットしているか

- Android は「同じアプリ ID を上書きインストールできるのは、同じ鍵で署名された APK だけ」
  という制約があります。CI のランナーが毎回作る debug 鍵では、新しいリリースが前の版を
  上書きできません（インストール時に「アプリがインストールされていません」で失敗します）。
- GitHub のシークレットをこのリポジトリに設定できない環境でも、リリースを再現できるようにするため、
  固定の鍵をリポジトリに置いています。

## 何を守らない鍵か

- このアプリはゼロ知識（E2EE）で、**秘密鍵とマスターパスワードは端末の外に出ません**。
  署名鍵は「配布物が同じ作者の更新か」を示すだけで、ボルトの中身を復号する力はありません。
- 第三者がこの鍵で別の APK を作ることは可能です。そのため配布は GitHub Releases の
  URL を本人が確認して行う前提で、リリースノートに必ずビルド元のコミットを書きます。

## 自分の鍵に差し替える

リポジトリの Secrets に次の 4 つを置くと、ワークフローはそちらで署名します
（`android/keystore/signing.properties` と `zekey-debug.keystore` は不要になります）。

| Secret | 内容 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `.jks` を base64 にしたもの |
| `ANDROID_KEYSTORE_PASSWORD` | ストアのパスワード |
| `ANDROID_KEY_ALIAS` | 鍵のエイリアス |
| `ANDROID_KEY_PASSWORD` | 鍵のパスワード |

差し替えたあとは、必ず `versionCode` を増やしてからタグを打ってください。
