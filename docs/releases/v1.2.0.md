# Zekey 2FA v1.2.0

**Aegis 2FA から Zekey 2FA へ全面改名**したリリースです。機能（ゼロ知識同期・TOTP/HOTP・
パスキー・移行・ゴミ箱・複数ボルト）はそのままで、名前・配信 URL・Android のアプリ ID が変わります。

## 名前と配信先

| | 旧 | 新 |
| --- | --- | --- |
| アプリ名 | Aegis 2FA | **Zekey 2FA** |
| Web 版 | `https://yuushi0911.xsrv.jp/aegis/` | **`https://yuushi0911.xsrv.jp/zekey/`** |
| リポジトリ | `yuushi-labs/aegis-2fa` | **`yuushi-labs/zekey-2fa`** |
| Android アプリ ID | `com.yuushilabs.aegis` | **`com.yuushilabs.zekey`** |
| ディープリンク | `aegis://login`・`aegis://sync` | **`zekey://login`・`zekey://sync`** |
| 配布ファイル | `aegis-android-v1.1.2.apk` / `aegis-php-xserver-v1.1.2.zip` | `zekey-android-v1.2.0.apk` / `zekey-php-xserver-v1.2.0.zip` |

- 旧 `/aegis/` には 301 リダイレクト（`/zekey/`）を置ける `.htaccess` を同梱しています。
- Android は **別アプリ**（アプリ ID が変わるため上書き更新ではなく新規インストール）です。
  ボルトは「アプリでログイン」または同期コードで引き継げます。

## 既存データの引き継ぎ

- **Xserver の PHP 版**: 新しい場所は `public_html` の外の `zekey-data/zekey.db`。
  初回アクセス時に旧 `/aegis/` の `aegis-data/aegis.db` を見つけると、`VACUUM INTO` で
  一貫したコピーを作ってから新しい場所を使います（WAL の未チェックポイント分も含む）。
  コピーできない環境では旧 DB をそのまま使い続け、どちらの場合も旧 DB は消しません。
- **暗号形式は不変**: 既存ボルトの AAD・verifier・封筒 `format` は旧名の識別子
  （`aegis-vault-v1` 等）のまま維持しているため、これまでに作ったボルト・バックアップ
  （`.aegis` / `.zekey`）は同じパスワードでそのまま開けます。
- **ブラウザの保存データ**: IndexedDB は同じオリジンなので、`/zekey/` でも端末のボルトを
  そのまま認識します（DB 名は内部識別子として旧名のまま）。

## そのほか

- OGP 画像・アイコン・robots.txt / sitemap.xml・JSON-LD・canonical を `Zekey 2FA` と
  `https://yuushi0911.xsrv.jp/zekey/` に更新しました（`og-image.png` も作り直し）。
- Search Console の確認ファイル（`google99620fefa840786a.html`）を同梱しました。
- バージョン: Web / PHP / Android 共通 `1.2.0`（Android `versionCode 5`）。
