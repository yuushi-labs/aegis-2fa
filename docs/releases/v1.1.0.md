## Aegis 2FA v1.1.0

Android ネイティブアプリを追加し、PHP（Xserver 用）ZIP と Android APK を GitHub Release で
まとめて配布するようにしました。

### Android アプリ（新規）

- **ゼロ知識同期**: 接続先は `https://yuushi0911.xsrv.jp/aegis` 固定。PBKDF2-HMAC-SHA-256 600,000 回 +
  AES-256-GCM。サーバーに置かれるのは暗号文だけです。
- **サイトからそのままログイン**: サイト版の「📱 アプリでログイン」を押すとアプリが開き、
  同期コードと鍵で最新のボルトを取得して**パスワード入力なしでアンロック済みの一覧**になります。
- **TOTP / HOTP**: SHA-1/256/512、6/8 桁、残り時間リング、ワンタップコピー（30 秒で自動クリア）。
- **追加は 3 通り**: 手入力（サービス候補つき）・QR スキャン（カメラ／画像）・
  Google Authenticator 移行。`otpauth://` の手入力欄はありません。
- **ロック**: マスターパスワード、指紋 / 顔認証（BiometricPrompt）、自動ロック（なし〜30 分）。
- **その他**: 30 日ゴミ箱、メモ・復旧コード、複数ボルト、重複チェック、並び順、同期端末一覧。
- 権限は `INTERNET` / `CAMERA` / `USE_BIOMETRIC` / `USE_FINGERPRINT`（API 26–27 の指紋用）のみ。
  バックアップにもボルトを載せません。

インストール: `aegis-android-v1.1.0.apk` を端末で開き、「提供元不明のアプリ」を許可してインストール。
上書き更新するには同じ署名鍵が必要です（CI は固定の配布鍵で署名しています）。

### PHP（Xserver 用）

- `aegis-php-xserver-v1.1.0.zip` は中に `aegis/` フォルダを含みます。`public_html/` で展開すると
  `public_html/aegis/` になり、そのまま動きます（Composer / Node 不要）。
- 中身は Web 版 v1.1.0 と同じ画面・同じ API です。
