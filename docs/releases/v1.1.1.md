## Aegis 2FA v1.1.1

Android アプリの同期不具合（`http_400`）を直し、一覧まわりの操作感を作り直し、
**GitHub Releases からのアプリ内アップデート**を追加しました。
PHP（Xserver 用）ZIP と Android APK をまとめて配布します。

### 同期（不具合修正）

- **「今すぐ同期」で `http_400` になっていた不具合を修正**。ローカルに未送信の変更が無い
  （`envelope.revision <= 最後に同期した revision`）ときに `PUT` を送っていたのが原因でした。
  サーバーは「次の revision が基準以下」の書き込みを `400 revision_must_advance` で拒否します。
  いまは未変更なら `GET` して取りに行きます。サイトの「📱 アプリでログイン」直後や、
  同期コードで接続した直後に起きていた症状です。
- **双方向同期**: 送る前にサーバーを見て、新しいアカウントや削除（tombstone）を取り込みます。
  ロック中は暗号文の封筒だけを採用し、解錠中は復号してマージ（新しい `updatedAt` を優先）。
  差分が無ければ送りません。マージ結果を送れなかった場合も手元に保存し、次の同期で送ります。
- サーバーにボルトが無い（404）ときは base 0 で作り直し、`revision 0` の封筒は送る前に
  1 以上へ進めます（壊れた封筒を送って 400 になる経路を塞ぎました）。
- エラー本文の `error`（`revision_must_advance` / `invalid_body` / `not_found` …）を読んで、
  画面には日本語のメッセージ（「サーバーに接続できませんでした」「もう一度同期すると自動で合わせます」）を出します。
  生の `http_400` は設定の「詳細」にだけ表示します。
- `PUT` の JSON が PHP 版の検証（`Validation.php`、未知キーを拒否する strict）と
  キー単位で一致することを単体テストで確認しています。

### Android の UI / UX

- **引っ張って同期**（Pull-to-Refresh）。同期が有効なときだけ反応します。
- ヘッダーに**ボルト名**（タップでクイック切替シート）と**同期状態ピル**
  （同期済み / 同期待ち / エラー / 要確認 / ローカルのみ）。エラーはタップで詳細と再試行。
- **残り時間リングを滑らかに**（100ms 更新 + アニメーション）。残り 5 秒以下は数字とコードを警告色に。
- **カードをタップでコピー**（触覚フィードバック + 「コピー済み ✓」を 1.5 秒表示）。
  編集・ピン・削除は `⋮` のメニューに整理し、「ピン / メモ / 未使用 N」の文字羅列を
  小さなアイコンとバッジに置き換えました。
- 検索は開閉アニメーション、`×` のクリアボタン、ヒット件数表示。
- 詳細画面: コードを大きく、コピーを主ボタンに。秘密鍵は表示/非表示を切り替え可能。
  項目は区切り線つきの行に整理。戻るはアイコン、削除はメニューと下部のカードへ。
- 追加画面: 種別・サービス・秘密鍵をカードで整理し、追加ボタンを画面下に固定。
  IME の「次へ / 完了」に対応。サービス候補は折り返し表示。
- 設定: セキュリティ項目を区切り線つきの行に統一。同期エラーは日本語 + 「詳細を見る」。
  アプリのバージョンと「アップデートを確認」を設置。
- セットアップ / ロック画面: パスワードの表示切替、IME の「完了」で解錠、余白と階層を調整。

### アプリ内アップデート（新規）

- `https://api.github.com/repos/yuushi-labs/aegis-2fa/releases/latest` を
  `If-None-Match`（ETag）付きで確認。`304 Not Modified` はレート制限を消費しないので、
  起動・復帰のたびに確認できます（連打は 20 秒でまとめる）。
- `tag_name` と `.apk` アセット（`aegis-android-*.apk`、サイズ・`sha256` ダイジェストがあれば照合）を読み、
  `BuildConfig.VERSION_NAME` と比較して**新しいときだけ**「vX.Y.Z があります」とリリースノート要約を表示。
- 「今すぐ更新」で `cacheDir/updates/` へ `.part` 経由でダウンロード（進捗 % 表示）。
  完了後、`FileProvider` 経由でシステムのインストーラを開きます。
  「提供元不明のアプリ」が未許可なら、設定（`ACTION_MANAGE_UNKNOWN_APP_SOURCES`）へ案内します。
- 起動時とダウンロード前に、実行中以下のバージョンの APK・`.part`・見覚えのないファイルを自動削除
  （未インストールの新しい APK は残す）。
- 設定画面に現在のバージョンと「確認」ボタン。「後で」を選んだバージョンは一覧のバナーに出さず、
  設定にだけ残します。

### PHP（Xserver 用）

- `aegis-php-xserver-v1.1.1.zip` は中に `aegis/` フォルダを含みます。`public_html/` で展開すると
  `public_html/aegis/` になり、そのまま動きます（Composer / Node 不要）。
- バージョンは `1.1.1`（`/api/health` も返します）。
